# Sanjana Valentine ❤️

Static HTML/CSS/JavaScript surprise with an anime-style couple image. No backend or database.

Keep `index.html` and the `assets` folder together.

## Test locally
Open `index.html` in a browser or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Your URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

The opening screen is more compact. After YES, the anime image and short message fit more comfortably on mobile and desktop. The page can scroll vertically on short screens so content is not clipped.
